Procedura pracy

  1. synchronizacja
  2. branch
  3. zmiana
  4. commit
  5. push
  6. PR
Polecenie Przykład Opis
git clone `git clone URL` Pobranie repozytorium i utworzenie lokalnego katalogu.
git status `git status` Sprawdzenie gałęzi oraz plików zmienionych i przygotowanych.
git add `git add docs/warp/git.md` Dodanie konkretnego pliku do obszaru staging.
git commit `git commit -m "docs: add Git cheatsheet"` Zapis przygotowanych zmian z czytelnym komunikatem.
git push `git push -u origin feature/git-cheatsheet` Publikacja nowej gałęzi i ustawienie śledzenia.
git pull `git pull --ff-only origin main` Pobranie zmian bez tworzenia nieoczekiwanego merge commita.
git fetch `git fetch origin` Pobranie informacji o zmianach bez modyfikowania plików roboczych.
git branch `git branch` Wyświetlenie lokalnych gałęzi i oznaczenie aktywnej.
git switch `git switch -c feature/nazwa` Utworzenie gałęzi roboczej i przełączenie na nią.
git log `git log --oneline -5` Skrócony podgląd pięciu ostatnich commitów.
